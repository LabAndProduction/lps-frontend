Чтобы рассчитать молярную концентрацию, нужно разделить количество растворённого вещества в молях на объём раствора в литрах: C = n / V. Если дана масса, сначала находят n = m / M, где M - молярная масса из таблицы Менделеева. Например, 5,85 г NaCl в 250 мл раствора - это 0,1001 моль на 0,250 л, то есть 0,400 моль/л. Ниже - как рассчитать молярную концентрацию в типичных учебных задачах, как переводить ммоль/л и мг/л и чем молярность отличается от моляльности.

Что такое молярная концентрация

Формула у этой величины одна, остальные расчёты выводятся из неё. Молярная концентрация показывает, сколько молей вещества содержится в одном литре раствора:

C = n / V

  • C - молярная концентрация, моль/л (часто пишут М: «0,1 М раствор» - это 0,1 моль/л);
  • n - количество вещества, моль;
  • V - объём всего раствора (не растворителя), л.

В учебниках встречаются обозначения c, Cм и квадратные скобки: [H⁺] = 0,01 моль/л. Строгое определение молярной концентрации в СИ даётся в моль/м³, но в лаборатории почти всегда работают с моль/л и ммоль/л. 1 моль/м³ = 0,001 моль/л = 1 ммоль/л.

Из этой же формулы выводятся две другие, которые нужны в задачах:

  • n = C · V - сколько молей содержится в заданном объёме;
  • V = n / C - какой объём раствора содержит нужное количество вещества.

Главное правило - объём в литрах. Если объём дан в миллилитрах, его делят на 1000: 250 мл = 0,250 л, 75 мл = 0,075 л.

Молярная масса и количество вещества - Откуда берётся n

В условии задачи количество вещества редко дано напрямую. Обычно известна масса навески, и тогда вопрос, как найти количество вещества в растворе, решает вторая формула:

n = m / M

  • m - масса вещества, г;
  • M - молярная масса, г/моль. Её считают как сумму атомных масс всех атомов в формуле.

Молярная масса и количество вещества связаны так же, как цена за штуку и количество штук: масса - это «сумма», молярная масса - «цена одного моля». Объединив две формулы, получаем рабочую формулу для расчёта по навеске:

C = m / (M · V)

Молярные массы, которые чаще всего встречаются в задачах:

Гидроксид натрияNaOH40,00
Хлорид калияKCl74,55

Для кристаллогидратов молярную массу берут вместе с водой - это частая ловушка, её разбираем в задаче 3. На этикетке реактива обычно указана формула именно той формы, что лежит в банке, поэтому перед расчётом стоит сверить её с формулой в условии. Если работаете с реальными реактивами и стандартами, молярную массу удобно взять прямо с упаковки.

Решённые задачи на молярную концентрацию

Сначала общий порядок действий, затем четыре задачи: по массе, по количеству вещества, по кристаллогидрату и по миллиграммам.

Как рассчитать молярную концентрацию по массе - Порядок действий

Вот как рассчитать молярную концентрацию в любой задаче, где известна масса растворённого вещества и объём раствора:

  1. Записать формулу вещества и проверить, безводное оно или кристаллогидрат.
  2. Посчитать молярную массу M, г/моль, с двумя знаками после запятой.
  3. Найти количество вещества: n = m / M.
  4. Перевести объём раствора в литры.
  5. Разделить: C = n / V.
  6. Проверить порядок величины: учебные растворы обычно лежат в диапазоне 0,001-2 моль/л. Ответ 0,0004 моль/л вместо 0,4, то есть в тысячу раз меньше ожидаемого, почти всегда означает, что объём остался в миллилитрах.
  7. Округлить ответ по наименее точному исходному числу (обычно 2-3 значащие цифры) и записать единицы.

Задача 1. Масса соли и объём раствора

Условие. В мерной колбе на 250 мл растворили 5,85 г NaCl и довели водой до метки. Найти молярную концентрацию.

Решение.

  1. M(NaCl) = 22,99 + 35,45 = 58,44 г/моль.
  2. n = 5,85 / 58,44 = 0,1001 моль.
  3. V = 250 мл = 0,250 л.
  4. C = 0,1001 / 0,250 = 0,4004 моль/л.

Ответ. C(NaCl) ≈ 0,400 моль/л (0,400 М).

Задача 2. Дано количество вещества

Условие. В 75 мл раствора содержится 0,015 моль HCl. Чему равна концентрация?

Решение. n уже дано, осталось перевести объём. V = 75 / 1000 = 0,075 л. C = 0,015 / 0,075 = 0,20 моль/л.

Ответ. 0,20 моль/л - две значащие цифры, как в исходных 0,015 моль и 75 мл.

Задача 3. Кристаллогидрат

Условие. 12,48 г медного купороса CuSO₄·5H₂O растворили и получили 500 мл раствора. Найти молярную концентрацию CuSO₄.

Решение.

  1. M(CuSO₄·5H₂O) = M(CuSO₄) + 5 · M(H₂O) = 159,607 + 5 · 18,015 = 159,607 + 90,075 = 249,68 г/моль.
  2. n = 12,48 / 249,68 = 0,04998 моль. Один моль купороса даёт один моль CuSO₄, поэтому n(CuSO₄) = 0,04998 моль.
  3. C = 0,04998 / 0,500 = 0,09996 моль/л.

Ответ. C(CuSO₄) ≈ 0,100 моль/л. Если по ошибке взять молярную массу безводной соли 159,61 г/моль, получится 0,156 моль/л - завышение больше чем в полтора раза.

Задача 4. Миллиграммы и миллилитры

Условие. В 50 мл раствора растворено 37,3 мг KCl. Найти концентрацию в моль/л и ммоль/л.

Решение. Удобный приём: миллиграммы делить на молярную массу - получаются миллимоли. n = 37,3 / 74,55 = 0,5003 ммоль. Дальше ммоль на мл - это то же самое, что моль на литр: C = 0,5003 / 50 = 0,01001 моль/л.

Ответ. 0,0100 моль/л, или 10,0 ммоль/л.

Если даны граммы и литры, концентрацию в моль/л считают так же, только без приставок: граммы делят на M - получаются моли, моли делят на литры. Главное - не смешивать в одной формуле миллиграммы с литрами.

Как найти количество вещества в растворе по известной концентрации

Обратная задача встречается не реже прямой: концентрация известна, нужно узнать, сколько вещества взято с аликвотой. Ответ на вопрос, как найти количество вещества в растворе, даёт та же формула, переписанная как n = C · V.

Пример. Сколько молей и граммов NaCl в 35 мл раствора с C = 0,12 моль/л?

  1. V = 0,035 л.
  2. n = 0,12 · 0,035 = 0,0042 моль = 4,2 ммоль.
  3. m = n · M = 0,0042 · 58,44 = 0,245 г ≈ 0,25 г.

Количество вещества не меняется при разбавлении водой, поэтому из n = C · V сразу следует правило разбавления C₁ · V₁ = C₂ · V₂. Если 10 мл раствора 0,400 моль/л довести до 100 мл, новая концентрация C₂ = 0,400 · 10 / 100 = 0,0400 моль/л. Объёмы здесь можно оставить в миллилитрах - они в формуле стоят с обеих сторон и сокращаются.

Та же логика лежит в основе титриметрии: по объёму титранта известной концентрации находят n, а потом концентрацию пробы. Поэтому точность ответа там зависит от того, насколько правильно титровать с бюреткой получается на практике - ошибка в объёме сразу переходит в концентрацию.

Перевод ммоль/л в моль/л и мг/л

В медицине, анализе воды и пищевых продуктов концентрации чаще дают в ммоль/л или мг/л. Перевод ммоль/л в моль/л и мг/л делается по двум простым правилам, и обратный перевод из мг/л идёт по тем же шагам в обратном порядке:

  • ммоль/л → моль/л: разделить на 1000;
  • ммоль/л → мг/л: умножить на молярную массу в г/моль (1 ммоль вещества весит M миллиграммов).
Из чегоВо чтоДействиеПример

Пример 1. Глюкоза в крови 5,5 ммоль/л. Сколько это в мг/л и г/л? 5,5 · 180,16 = 990,9 мг/л ≈ 0,99 г/л. В моль/л - 0,0055.

Пример 2. В воде 100 мг/л ионов кальция. Сколько это в ммоль/л и моль/л? 100 / 40,08 = 2,495 ммоль/л ≈ 2,50 ммоль/л, то есть 0,00250 моль/л.

Если концентрация дана в г/л, в моль/л её переводят делением на M: 23,4 г/л NaCl / 58,44 = 0,400 моль/л.

Для ионов берут молярную массу самого иона, а не соли, из которой он пришёл: если в условии «мг/л хлорид-ионов», делят на 35,45, а не на 58,44.

Чем отличаются молярность и моляльность

Разница в знаменателе, хотя названия почти одинаковые:

ВеличинаФормулаЕдиницыЧто в знаменателе
Молярность (молярная концентрация)C = n / V(раствора)моль/лобъём всего раствора
Моляльностьb = n / m(растворителя)моль/кгмасса только растворителя

Молярность зависит от температуры: при нагреве раствор расширяется, объём растёт, а C падает. Моляльность от температуры не зависит, поэтому её используют в расчётах температур кипения и замерзания растворов. Для разбавленных водных растворов (до 0,01-0,05 моль/л) числа почти совпадают, потому что литр такого раствора содержит около килограмма воды. Для концентрированных - расходятся заметно.

Если нужно понять, как рассчитать молярную концентрацию по известной моляльности, понадобится плотность раствора.

Пример. 58,44 г NaCl (ровно 1 моль) растворили в 1000 г воды. Плотность полученного раствора 1,038 г/мл. Найти моляльность и молярность.

  1. Моляльность: b = 1,000 / 1,000 кг = 1,000 моль/кг.
  2. Масса раствора: 1000 + 58,44 = 1058,44 г.
  3. Объём раствора: V = 1058,44 / 1,038 = 1019,7 мл = 1,0197 л.
  4. Молярность: C = 1,000 / 1,0197 = 0,981 моль/л.

Разница около 2% - уже больше, чем допуск мерной посуды. Поэтому «1 моль на килограмм воды» и «1 моль в литре раствора» - это разные растворы, и в ответе важно не перепутать единицы моль/кг и моль/л.

Типичные ошибки студентов

Большинство ошибок связано не с тем, что студент не знает, как рассчитать молярную концентрацию, а с единицами и невнимательно прочитанным условием.

  • Объём в миллилитрах. 0,1001 моль / 250 = 0,0004 вместо 0,400. Проверка порядка величины ловит эту ошибку сразу.
  • Объём растворителя вместо объёма раствора. «Растворили в 250 мл воды» и «довели до 250 мл» - разные условия. В первом случае точный объём раствора неизвестен без плотности.
  • Кристаллогидрат без воды. CuSO₄·5H₂O, Na₂CO₃·10H₂O, MgSO₄·7H₂O - молярную массу считают с кристаллизационной водой.
  • Масса соли вместо массы иона. В задачах на воду и кровь концентрация часто дана по иону. Молярная масса и количество вещества считаются для той частицы, о которой спрашивают в условии.
  • Путаница молярной и нормальной концентрации. Для H₂SO₄ 0,1 моль/л соответствует 0,2 н в реакциях полной нейтрализации. Если в условии «н» или «моль-экв/л», это другая величина.
  • Приставки при переводе единиц. При переводе ммоль/л в моль/л часто умножают на 1000 вместо того, чтобы делить. Проверка простая: в моль/л число всегда в 1000 раз меньше, чем в ммоль/л. При переводе в мг/л умножают на молярную массу, а не на 1000.
  • Лишнее округление в середине расчёта. Промежуточные значения держат с запасом в одну-две цифры, округляют только ответ.
  • Нет единиц в ответе. Число 0,4 без «моль/л» на зачёте не засчитают.

Что нужно из посуды и оборудования

Знать, как рассчитать молярную концентрацию, мало: расчёт точен настолько, насколько точны масса и объём, которые в него подставлены. Молярная масса и количество вещества берутся из расчёта, а масса навески и объём раствора - с весов и мерной колбы, и погрешность приходит именно отсюда. Для учебного практикума и рабочей лаборатории понадобятся:

  • Аналитические весы с дискретностью 0,1 мг - для навесок от десятков миллиграммов, например аналитические весы Sartorius Entris II. На технических весах с шагом 0,01 г навеска 0,05 г взвешивается с ошибкой до 20%.
  • Мерная колба класса А - именно она задаёт V в формуле. Для задач вроде первой подходит мерная колба на 250 мл класса А со шлифом.
  • Химический стакан, воронка, промывалка - чтобы растворить навеску и количественно перенести её в колбу.
  • Пипетки - для отбора аликвот и разбавлений по формуле C₁ · V₁ = C₂ · V₂.

Объём колбы, класс точности и шлиф подбирают под методику, и если колба покупается для своего практикума, полезно заранее понять, как выбрать мерную колбу под типичные объёмы растворов. Мерный цилиндр и стакан с делениями для точной концентрации не годятся: их погрешность в несколько раз больше, чем у мерной колбы.

Частые вопросы

Как рассчитать молярную концентрацию, если известна только массовая доля?

Нужна ещё плотность раствора. Берут 1 л раствора, находят его массу 1000 · ρ (ρ в г/мл), массу вещества (масса раствора · w), затем n = m / M - это и будет C в моль/л. Без плотности задача не решается.

Как найти количество вещества в растворе, если объём в мл, а концентрация в ммоль/л?

Перемножить и разделить на 1000: n (ммоль) = C (ммоль/л) · V (мл) / 1000. Например, в 20 мл раствора 5 ммоль/л содержится 20 · 5 / 1000 = 0,1 ммоль.

Моль/л как посчитать, если концентрация дана в мг/л?

Разделить мг/л на молярную массу - получатся ммоль/л, затем разделить на 1000. Например, 250 мг/л сульфат-ионов SO₄²⁻ (M = 96,06 г/моль): 250 / 96,06 = 2,60 ммоль/л = 0,00260 моль/л.

Как рассчитать молярную концентрацию после смешивания двух растворов?

Складывают не концентрации, а количества вещества и объёмы: C = (C₁V₁ + C₂V₂) / (V₁ + V₂). Например, 100 мл 0,2 М и 100 мл 0,4 М одного вещества дают 0,3 М, а не 0,6 М (объём считается аддитивным для разбавленных растворов).

Почему молярность зависит от температуры?

Потому что в знаменателе объём, а он меняется при нагреве. Мерная посуда откалибрована при 20 °C, и раствор доводят до метки при этой температуре.

Чтобы понимать, как рассчитать молярную концентрацию в любой задаче, достаточно держать в голове цепочку m → n → C: масса делится на молярную массу, моли делятся на литры, единицы проверяются на каждом шаге. Остальное - перевод ммоль/л в моль/л и мг/л, разбавление, моляльность - выводится из этих же двух формул.
